# Pokemon-Auto-Battler
Pokemon Auto Battler sample using PokeAPI
1. Used Poke API
2. The API has the Stats and Sprites of all Pokemon. Has the mechanics of Turn Based combat compares the Speed factors in which goes first.
3. Used Observer Pattern because of familiarity, most of the functions are event driver also to isolate the Gameplay to UI and potential extentions such us Sound and VFX in future development.
